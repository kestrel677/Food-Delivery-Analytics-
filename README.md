# Food Delivery Dashboard & AI Insights

A data science project analyzing food delivery performance metrics using Pandas, integrated with the Groq API (Llama/GPT-OSS model) to generate automated executive business explanations.

## Features
- **Data Analysis**: Processes delivery datasets to evaluate weather impacts, traffic density delays, and courier performance metrics.
- **AI Integration**: Automatically queries the Groq API to convert raw analytics into clean, professional, plain-text business insights.
- **Secure Credentials**: Utilizes Kaggle Secrets to manage API keys securely without hardcoding.

## Tech Stack
- Python
- Pandas
- Groq API
- Kaggle Notebooks
